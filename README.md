# Buffet NPK

Сайт студенческого буфета НПК.

## Установка и запуск проекта

### 1. Установите программы

- [Node.js](https://nodejs.org/) (версия LTS).
- [Visual Studio Code](https://code.visualstudio.com/).

### 2. Скачайте проект

1. Откройте VS Code.
2. Нажмите `Ctrl + Shift + P`.
3. Найдите `Git: Clone`.
4. Вставьте ссылку:

```text
https://github.com/Rezzhwxc/buffet-npk.git
```

5. Выберите папку для сохранения проекта.
6. После загрузки нажмите **Open**.

### 3. Установите зависимости

В VS Code откройте **Terminal → New Terminal** и выполните:

```powershell
npm install
```

Затем установите `dotenv`:

```powershell
npm install dotenv
```

### 4. Настройте API

1. В корне проекта создайте файл `.env.local`.
2. Скопируйте в него содержимое `.env.example`.
3. Укажите выданные логин и пароль 1С.

**Важно:** файл `.env.local` содержит конфиденциальные данные. Не публикуйте его в GitHub и не передавайте пароль посторонним.

### 5. Запустите сервер

Для работы API необходимо запустить серверную часть проекта.

Откройте первый терминал VS Code и выполните:

```powershell
node server.js
```

Не закрывайте терминал во время работы сервера.

### 6. Запустите сайт

Откройте второй терминал (**Terminal → New Terminal**) и выполните:

```powershell
npm run dev
```

После запуска откройте сайт в браузере:

http://localhost:5173/pages/index.html

### 7. Остановка проекта

Для остановки сервера и сайта перейдите в соответствующие терминалы и нажмите:

```text
Ctrl + C
```

## Важная информация

- Для полноценной работы проекта одновременно должны работать `server.js` и Vite.
- При первом запуске необходимо установить зависимости.
- При изменении настроек API проверьте содержимое `.env.local`.
- Не загружайте `.env.local` в публичный репозиторий.
